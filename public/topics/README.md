# Topic images

Drop images here to illustrate vocabulary. Reference them from
`composables/useTopics.js` with a leading slash, e.g.:

```js
{ c: '苹果', p: 'píngguǒ', en: 'apple', img: '/topics/fruit/apple.jpg' }
```

Recommended: square (1:1), ≤ 200 KB, ~400×400 px JPG/WebP/PNG.
If both `img` and `e` (emoji) are set, the image is shown.
